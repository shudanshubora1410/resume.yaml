### 🎯 ResuMatch — Flagship Final Year Project

> Rule-Based Recruitment Platform with Transparent ATS — **92 Java files, 13 packages, production-grade**

```
🐙 Code  →  https://github.com/shudanshubora1410/ResuMatch
```

**Highlights:**

- Full-stack recruitment platform built as Final Year B.Tech IT project at GLBITM
- Two cooperating score services: `GeneralScoreService` (resume-only) and `CompanyScoreService` (job-matched)
- 5-component general score (out of 100) and 5-component company score — same formula shown to both candidate and recruiter
- 48-skill canonical dictionary with alias matching (`js → javascript`, `reactjs → react`, `c++ → cpp`)
- Regression-tested alias index — shorter skills never shadow longer ones (e.g. "Java" inside "JavaScript")
- Three-sided workflow: Seeker, Recruiter, Admin with role-scoped dashboards
- What-if simulator, skills gap insight, version comparison, bulk action by score band
- Resume parsing via Apache PDFBox (PDF, DOCX)
- 11 JPA entities, 11 repositories, 12 services, 7 REST controllers, 17 HTML pages
- 10 JUnit tests; H2 file mode by default, MySQL 8 profile for production
- One-click demo seeder — 3 seekers, 3 recruiters, 6 jobs, 15 applications
- Optional Google Gemini integration with deterministic template fallback

**Tech:** `Java 17` `Spring Boot 3.2` `Spring Data JPA` `Hibernate` `H2` `MySQL 8`
`Apache PDFBox` `Chart.js` `Maven` `Vanilla JS` `HTML5` `CSS3`

## 🚀 How to Compile Resume

### Option 1 — Overleaf (Recommended — No Installation)

1. Go to [https://www.overleaf.com](https://www.overleaf.com)
2. Click New Project → Blank Project
3. Delete all existing code in editor
4. Paste the entire contents of `main.tex`
5. Click Recompile button
6. Download PDF from top left

### Option 2 — Local (pdflatex)

```bash
# Requires TeX Live installed on your system
git clone https://github.com/shudanshubora1410/resume.git
cd resume
pdflatex main.tex
```

### Required LaTeX Packages

```
inputenc    fontenc     lmodern     geometry
titlesec    enumitem    hyperref    xcolor
fontawesome5            tabularx    array
tikz        microtype
```
